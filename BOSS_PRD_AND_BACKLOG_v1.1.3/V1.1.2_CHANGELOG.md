## v1.1.2 (15 November 2026)

### Breaking schema corrections (would have caused Flyway migration failure)

- **SCHEMA V045 — 4 tenants FK fixes:** `item_categories.tenant_id`, `asset_type_configs.tenant_id`, `inspection_parameter_templates.tenant_id`, `inspection_parameter_template_lines.tenant_id` all changed from `REFERENCES tenants(id)` → `REFERENCES tenant_registry(id)` (v1.0-era name that was missed in v1.1.1)
- **SCHEMA V047 — duplicate routing_templates resolved:** V047 now includes `ALTER TABLE job_stages DROP COLUMN routing_op_id` and `ALTER TABLE production_jobs DROP COLUMN routing_id` before `DROP TABLE routing_operations` and `DROP TABLE routing_templates` before the new `CREATE TABLE` statements. Without this, V047 would have failed with "table already exists" (routing_templates) and "foreign key violation" (job_stages.routing_op_id).
- **SCHEMA Flyway version names V045b/V046a → V045_1/V046_1:** Flyway does not accept alphabetic sub-versions. Renamed to underscore notation.

### New migrations added (were listed in index but had no DDL)

- **V041:** `notifications` table (tenant-scoped, RLS-eligible)
- **V041:** `notification_preferences` table (tenant-scoped, RLS-eligible)
- **V042:** `approval_requests` table (tenant-scoped, RLS-eligible)
- **V043:** FK backfill — `replenishment_requests.pr_id` now references `purchase_requisitions(id)`
- **V044:** `platform_admin_users` and `platform_audit_events` tables (platform-level, NO RLS by design)

### New tables added (were missing from DDL despite being referenced)

- **V034:** `frame_agreement_lines` table added (V034 migration title promised it; DDL was absent)
- **V035:** `replenishment_requests` table added (referenced in backlog stories; DDL was absent)

### Security corrections

- **V051 RLS — stock_movements added:** `stock_movements` has a `tenant_id` column but was absent from the V051 RLS policy loop. Security gap closed.
- **V051 RLS — 5 new tables added:** `notifications`, `notification_preferences`, `approval_requests`, `replenishment_requests`, `frame_agreement_lines` all added to the RLS array.

### Schema count correction

- Table count corrected from 88 (v1.1.1) to **91** (v1.1.2). The v1.1.1 count was wrong because it counted V047 routing tables as additions without subtracting the dropped V015 tables (net = 0), and missed the new V041–V044 tables and the two missing DDL tables from V034/V035.
