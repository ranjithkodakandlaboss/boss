## v1.1.1 (15 November 2026)

### Breaking corrections (would have caused deployment failure)
- **SCHEMA:** `tenant_onboarding_config.tenant_id` FK fixed: `REFERENCES tenants(id)` → `REFERENCES tenant_registry(id)`
- **SCHEMA:** `tenant_onboarding_config.onboarding_completed_by` FK fixed: `REFERENCES users(id)` → `REFERENCES app_users(id)`
- **SCHEMA:** V046 migration DDL added (was only a comment in v1.1) — adds `items.category_id` FK column and drops free-text `category` column

### Security corrections
- **SCHEMA:** V051 RLS array updated to include 5 V045 tables that were missing (`item_categories`, `asset_type_configs`, `inspection_parameter_templates`, `inspection_parameter_template_lines`, `tenant_onboarding_config`) — data isolation gap closed

### New migrations
- **V045b:** `config_categories` global registry table (platform-wide, no tenant_id)
- **V046a:** `tenant_config_options` + `tenant_config_option_history` (tenant-scoped configurable values)
- **V047:** Versioned `routing_templates` + `routing_template_stages` (replaces simple v1.1 routing tables; active jobs preserve original template version)
- **V052:** Indexes added for all new tables

### New product capability
- **EPIC-18 — Configurable Business Values and Workflows** added as new mandatory EPIC
  - 3-tier configuration hierarchy: BOSS System Defaults → Industry Template → Tenant Customisation
  - 30+ configurable category codes across all domains
  - Versioned routing templates with historical snapshot preservation
  - All dropdowns must come from `/api/v1/config/options/{category}` — no hard-coded lists anywhere
  - `config.yaml` OpenAPI contract added
  - 6 new backlog stories: EPIC-18-S001 through EPIC-18-S006
